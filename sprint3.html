Inleiding

In deze sprint heb ik mij voornamelijk bezig gehouden met de database. Onze database bevatten onder andere de afbeeldingen en prijzen van producten. Mijn groepsgenoot had aangegeven dat hij vorige jaar met Firebase had gewerkt en dat hij dit fijn vond werken. Aangezien dit de eerste keer was dat ik hier gebruik van maakte was dit best een uitdaging voor mij. Ik had in het begin geen eens een idee hoe ik entries toe moest voegen in de database. Het heeft me hierdoor ook veel tijd gekost deze sprint om dit allemaal werkend te krijgen.

Firebase Storage

Hier zie je hoe wij de opslag ingericht hebben. Ik heb dit zo ingericht omdat ik de profielen en categorieen gescheiden wil houden. De reden hiervoor is zodat wanneer wij de database willen uitlezen met de AI, het een stuk makkelijker wordt om de juiste afbeeldingen te koppelen aan wat de AI wilt aanraden aan de gebruiker.
Ook zie je dat ik bij de namen de kleur van het product heb genoteerd. Ook dit heb ik gedaan zodat we weten wat voor artikel het is zonder de afbeelding te hoeven openen.

Firestore

Hier zie je onze echte database. Hier had ik het meeste moeite mee en had ik ook een groepsgenoot om hulp moeten vragen. Aangezien dit nieuw was wist ik onder andere niet hoe ik de koppeling moest maken naar de storage. Het was ook fijn om dit samen met een groepsgenoot te doen aangezien dit allemaal handmatig moest.

Data uitlezen

De code voor het uitlezen van de data heb ik ook gemaakt. Ik heb geschreven in python. Dit was vooral om te testen of we de data in de front end kunnen zien. Ook heb ik een functie gemaakt om te controleren of we de afbeeldingen ook konden zien. Dit heb ik gedaan door een tijdelijke link te maken van de afbeeldingen.
